# AI Practicals

Lab practicals for **Artificial Intelligence (01AI0511)**, Department of AI, ML & DS, Faculty of Engineering & Technology. Each practical is a PDF with the aim, theory, Python implementation, and output.

## Practicals

| # | Topic |
|---|-------|
| 1 | Python setup and a simple reflex agent (cleaning robot) |
| 2 | BFS, DFS, and Uniform-Cost Search on a maze graph |
| 3 | A* search for the 8-puzzle, comparing heuristics |
| 4 | Tic-Tac-Toe agent with Minimax and Alpha-Beta pruning |
| 5 | Rule-based expert system for computer troubleshooting |
| 6 | N-Queens CSP using backtracking and consistency checking |
| 7 | Naive Bayes probabilistic classifier |
| 8 | Spam message detector (text classification + ethics/explainability) |
| 9 | STRIPS planning in Blocks World |
| 10 | Value Iteration in a Grid World (MDP) |
| 11 | Logical inference with propositional logic |
| 12 | Comparing k-NN, Decision Tree, and Naive Bayes |

## Usage

Open any `AI_Practical - N.pdf` to view the practical. Code is written in Python 3; some practicals use `scikit-learn`.
